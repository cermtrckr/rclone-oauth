# Privacy Policy

Last updated: September 30, 2026.

This application is a personal OAuth configuration for rclone,
used only by its owner to synchronize files between a local
computer and Google Drive.

## Access and use

The application requests Google Drive access to list, read,
upload, update, rename and delete files as required for
synchronization and backups configured by the owner.

## Storage and sharing

Synchronized files and backups are stored on the owner's
computer and Google Drive. OAuth credentials are stored
in the owner's local rclone configuration.

This application does not sell Google user data or share it
with advertisers. Google user data is not used to train AI models.

This website does not receive Google Drive files or OAuth tokens.

## Revoking access

The owner can revoke access through the Google Account
third-party connections settings and remove the local
rclone configuration and synchronized copies.

## Contact

For questions, contact the repository owner:
